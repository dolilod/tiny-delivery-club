## Handoff for Doli

Built: four short delivery routes, robot courier, star parcels, walls, friendly clouds, Santai/Adventure modes, hearts, Retry, Pause, Replay, a two-second level-4 cloud nap, ID/EN labels, optional sounds and credits. Everything runs from the local docs folder. Maps, names, strings, colors and rules are editable in docs/content.js.

To launch, open a terminal in this project folder and run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs
```

Open http://127.0.0.1:8000. Start with Santai. Hold the arrow buttons, or use the keyboard arrows/WASD. Collect every star, then return to the house. Escape or Jeda pauses. Close the server with Ctrl+C when finished.
